## 🛠️ Tech Stack & Features
- **Frontend**: React 18, Vite 5, Tailwind CSS
- **Design**: Dark Mode by default with Light/Dark switcher, Glassmorphism cards, responsive layouts
- **Interactive Features**:
  - Filterable Projects Grid (AI/ML & Python, Data & Analytics, Web Development, Software Development)
  - Deep-dive Project Modal with architecture highlights and medical disclaimer
  - Interactive Skills Matrix with category filtering
  - Chronological Education & Experience Timelines (QSpiders, Cognifyz, Path Creators, Nil Tech EDU)
  - Verified Certifications & Honors (NPTEL Java, NPTEL Python, Google Data Analytics, Power BI, HackerRank)
  - Direct Contact Actions (one-click copy, mailto/tel links, Formspree-ready contact form)
  - Interactive Resume Viewer with Print / Save PDF capability

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
